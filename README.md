# 영화 예매 시스템 (Movie Reservation System)

쉽고 빠르게 영화를 예매할 수 있는 프로그램을 구현합니다.

## 기능 구현 목록

### 1. 영화 및 상영 관리
- [x] Movie 도메인 모델 구현
  - 영화 제목, 상영 시간, 상영 기간 관리
- [x] Screening 도메인 모델 구현
  - 영화별 상영 시간표 관리
  - 하루 여러 차례 상영 지원

### 2. 좌석 관리
- [x] SeatType 열거형 구현
  - S석: 18,000원
  - A석: 15,000원
  - B석: 12,000원
- [x] Seat 도메인 모델 구현
  - 좌석 번호, 타입, 예약 상태 관리
- [x] 이미 예약된 좌석 선택 방지 기능

### 3. 할인 정책
- [x] 무비데이 할인 정책 구현
  - 매월 10일, 20일, 30일 상영 시 10% 할인
- [x] 시간대 할인 정책 구현
  - 오전 11시 이전 또는 오후 8시 이후 시작 시 2,000원 할인
- [x] 복합 할인 적용 로직
  - 무비데이 할인(비율) → 시간 조건 할인(정액) 순서로 적용

### 4. 결제 시스템
- [x] 포인트 사용 기능
  - 예매 금액에서 직접 차감
- [x] 결제 수단별 추가 할인
  - 신용카드: 5% 할인
  - 현금: 2% 할인
- [x] 할인 적용 순서: 기본 할인 → 포인트 차감 → 결제 수단 할인

### 5. 예매 시스템
- [x] 단일 영화 예매 기능
- [x] 다중 영화 예매 기능
- [x] 시간 겹침 검증 기능
- [x] 예매 내역 관리

### 6. 사용자 인터페이스
- [x] 메인 애플리케이션 진입점 (Application.main())
- [x] 영화 목록 조회
- [x] 상영 시간표 조회
- [x] 좌석 선택 인터페이스
- [x] 예매 확인 및 결제
